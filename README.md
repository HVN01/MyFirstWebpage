# CSS-week1-HW1 — Exploring Vietnam

This repository contains the Week 1 Homework 1 project for **Introduction to CSS3** (Web Design for Everybody Specialization), structured following the `WD4E-Intro_to_CSS3/CSS-week1-HW1` layout.

## Repository Structure

```text
repository1/
├── README.md
├── index.html
├── places.html
├── gallery.html
├── css/
│   └── style.css
└── images/
    ├── ha-long-bay.jpg
    ├── hoi-an.jpg
    └── sapa.jpg
```

## Pages

- `index.html` — Home page introducing Vietnam's top travel destinations.
- `places.html` — Detailed highlights of Ha Long Bay, Hoi An Ancient Town, and Sapa.
- `gallery.html` — Photo gallery featuring local images from the `images/` folder.

## CSS Styling Summary (`css/style.css`)

All three HTML pages share a single stylesheet (`css/style.css`) implementing all required Week 1 styling rules:

- `body`: `font-family`, `font-size`
- `header`: `background-color`
- `nav`: `background-color`
- `main`: `background-color`, `font-size`
- `footer`: `background-color`
- `li`: `display`, `width`
- `h1`: `text-align`, `font-family`, `color`
- `p`: `line-height`
